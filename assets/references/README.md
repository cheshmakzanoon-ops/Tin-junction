# Reference policy

Reference material guides original modelling and objective visual review. It is not a licence to copy a model, photograph, livery, trademark, recording, or another game's art.

The repository contains no downloaded reference images. Add sources deliberately, with rights records and relevance.

## Current research and launch inventory

- [Reference registry](registry.json): seven primary-source, link-only records inspected on 2026-10-27, with rights distinctions and known limitations.
- [Rights record](RIGHTS.md): exact admission policy; no commercial image or mesh permissions implied.
- [Required launch kit](launch-kit.json): stable production IDs, responsible roles, priorities, variant counts and dimension status.
- [Design brief](DESIGN_BRIEF.md): coherent original direction, missing reference views and the required capture/critique sequence.

These are P10-T01 research and planning records, not an approved image board or finished production assets. Manufacturer names identify sources only. All required production entries remain planned; existing procedural entries remain prototypes. Further multi-view research belongs to each production task and cannot be skipped because a reference URL exists.

## For every reference item

Record a stable reference ID, creator/source, exact URL or original file, access date, subject, intended use, known dimensions, lighting/view limitations, applicable licence/permission and whether redistribution is allowed. Keep evidence of permission where required.

If redistribution is not permitted, keep a link and written observations rather than committing the image. A link-only research record must not be packaged into the app as an image asset. Do not assume search thumbnails, magazine scans, store photos or social posts are reusable.

## Required reference families

- Overall physical miniature railway composition.
- Locomotive silhouette, wheels, rods, bogies and couplers.
- Track cross-section, sleeper spacing, joiners and turnouts.
- Painted metal, brass, wood, ballast, model plaster, foliage and glazing.
- Miniature station/building thickness and lighting.
- Case hinge/frame/latch construction and closure envelope.
- Actual movement and low-speed mechanism behavior.

Prefer sources with dimensions, multiple angles and neutral-light views. Single dramatic photographs can be useful mood references but cannot verify hidden geometry or material colour.

## Comparison discipline

Compare the runtime object at a matching view/lighting/scale where feasible. Label differences attributable to lens, exposure, manufacturing variation or deliberate fictional design. Never call an inferred dimension “measured”.

Use the reference ID in the asset catalog and visual-review manifest. Re-review derivative assets when the governing licence or source changes. If the source disappears, preserve legally permitted metadata and permission proof; do not replace it with an unrelated image silently.

No generated concept image may stand in for a real-device screenshot or verified engineering measurement.
